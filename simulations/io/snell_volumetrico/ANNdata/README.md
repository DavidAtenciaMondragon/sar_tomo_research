# Bistatic SAR Neural Network Training Data

## Overview
This directory contains ANN datasets generated by proc/PROC_snell_volumetrico_test_script.m.
Each processing run stores one dataset group per processed SNR value.

## File Naming Convention
Files created in this folder use this pattern:

YYYYMMDD_HHMMSS_<datatype>_<snr>dB.<extension>

Examples:
- 20260321_100753_outputData_10.mat
- 20260321_100753_targetMask_10.mat
- 20260321_100753_XYZ_10.mat
- 20260321_100753_platformPositions_10.mat
- 20260321_100753_metadata_10.json

Notes:
- timestamp is generated inside the SNR loop, so each SNR can have a different timestamp.
- snr comes from SNRtoProc.

## Files Actually Saved in ANNdata

### 1) *_outputData_<snr>.mat
- Variable: outputData
- Description: Complex 3D back-projection result used as ANN input.
- Format: MATLAB MAT-file (-v7)

### 2) *_targetMask_<snr>.mat
- Variable: targetMask
- Description: 3D target mask used as ANN supervision/ground truth.
- Format: MATLAB MAT-file (-v7)

### 3) *_XYZ_<snr>.mat
- Variables: X, Y, Z
- Description: Cartesian processing grid coordinates in meters.
- Format: MATLAB MAT-file (-v7)

### 4) *_platformPositions_<snr>.mat
- Variables: PxT, PyT, PzT, PxR, PyR, PzR
- Description: Transmitter and receiver trajectory samples.
- Format: MATLAB MAT-file (-v7)

### 5) *_metadata_<snr>.json
- Fields written by the script:
  - timestamp
  - n
  - noisePower
  - fs
  - FreqPortadora
- Description: Minimal metadata for traceability/reproducibility.

## Important Clarification
Plot images are NOT saved in this ANNdata folder.
PROC_snell_volumetrico_test_script.m saves figures in:

io/snell_volumetrico/figures/proc/

with names like:
- YYYYMMDD_HHMMSS_isosurface_<snr>.png
- YYYYMMDD_HHMMSS_slice_<snr>.png

## Technical Notes
- Coordinate system: Cartesian X, Y, Z (meters)
- outputData type: complex double
- MAT version: -v7
